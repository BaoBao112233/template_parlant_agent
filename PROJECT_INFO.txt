═══════════════════════════════════════════════════════════════
  SETUP INSTRUCTIONS
═══════════════════════════════════════════════════════════════

1. Prerequisites:
   • Python 3.10+
   • Google Cloud service account
   • Docker (optional)

2. Configure:
   • Add service-account.json to project root
   • Copy .env.example to .env
   • Edit .env with your project ID

3. Run:
   Local:  ./setup.sh && python -m app.main
   Docker: docker-compose up -d

4. Access:
   • http://localhost:8000       Web UI
   • http://localhost:8800       Parlant Playground
   • http://localhost:8000/docs  API Documentation
